## 社会技術システム（4層）
```
社会・制度  会計基準/監査/労務/個人情報      壊れ方: 法令に触れる
 └ 組織    店舗運営本部/ネット通販部/経理    誰の仕事か決まらない

       └ ソフトウェア 同期/受取画面          落ちる/遅い/合わない
確かめる向き: 外→内 / 気づく向き: 内→外
```

## Complicated と Complex
```
Simple×数量     = Complicated（専門知識と時間で分かる／足し算）
Simple×相互作用 = Complex    （事後にしか分からない／掛け算）
複雑さは要素数でなく「絡み(complect)」から。Complexに詳細計画=最頻の誤り。
```

## 権力×関心×態度キューブ
```
          関心低        関心高
権力高  ①満足を維持   ②密接に管理
権力低  ③監視        ④情報提供
+態度(賛成/反対/不明)。最危険=権力高・関心低・態度不明→まず態度を確かめる。
```
